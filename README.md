# QRCode · 离线二维码生成器

把文本、网址或文件下载链接转换为二维码，方便在电脑与手机之间分享内容。纯 HTML / JavaScript 实现，无需安装依赖或启动后端。

## 获取与使用

**应用源码位于 `master` 分支**；默认 `main` 分支用于仓库介绍。

```bash
git clone --branch master https://github.com/wivnelo/QRCode.git
cd QRCode
```

用现代浏览器打开 `index.html`，保持它与 `qrcode-generator.js` 位于同一目录。

1. 输入或粘贴文本，支持中文、换行和 UTF-8 字符。
2. 选择纠错级别、每模块像素与边距；不确定时保留默认值。
3. 点击「生成二维码」，或按 `Command + Enter` / `Ctrl + Enter`。
4. 用手机扫码读取内容；也可以点击「下载 PNG」保存当前二维码。
5. 长文本会自动拆分，使用「上一张 / 下一张」切换并逐张下载或扫描。

## 能做什么

- 在浏览器本地生成二维码，无需账号、服务器或在线二维码服务。
- 自动选择二维码版本，支持 L / M / Q / H 四种纠错级别。
- 调整输出图像大小与二维码边距。
- 超出单张容量时按 Unicode 码点拆分文本。
- 下载当前页 PNG；多页文件名带有分段编号。
- 支持随系统切换深浅色界面。

## 扫码获取文本与文件的区别

| 输入内容 | 扫码后获得什么 |
| --- | --- |
| 普通文本 | 对应文本，具体展示方式取决于扫码工具 |
| 网页 URL | 网页地址，可由扫码工具打开 |
| 文件下载 URL | 下载地址；能否下载取决于链接权限和有效期 |
| 长文本 | 多张二维码中的各段文本，需要按顺序扫描并手动拼接 |

本项目**不提供文件上传、文件托管、二进制文件传输或扫码接收端**。「下载 PNG」保存的是二维码图片，不是输入内容对应的文件。

例如，要分享 PDF，请先获得接收方可以访问的下载链接，再将链接生成二维码。将本机文件路径编码为二维码，并不能让另一台设备访问该文件。

## 使用提示与隐私

- 生成过程在本地完成，页面没有上传输入内容的网络请求，也没有保存输入的持久化逻辑。
- 二维码没有加密，拿到图片的人可以读取其中内容。
- 长文本越多，二维码越密集；扫描困难时可缩短内容、放大显示或降低纠错级别。
- 多张二维码是独立文本片段，没有自动合并协议；扫码工具不会自动还原完整文本。
- 打开二维码中的外部链接会联网，并受目标网站规则约束。
